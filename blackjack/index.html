GLOSSAR

Wichtige Begriffe

Running Count
Laufende Summe der gesehenen Kartenwerte.
True Count
Running Count normiert auf die verbleibenden Decks.
Penetration
Anteil des Schuhs, der vor dem Mischen ausgespielt wird.
Index
Count-Schwelle für eine Abweichung von der Grundstrategie.
